Read this before you start

The VPN is not an optional last step. NX gets its licence from a server that only exists inside the campus network. If you install first and connect later, the licence screen accepts your entry and then NX fails to launch, which looks like a broken install and is not. Connect to GlobalProtect first — that is step 1 below.

This installer is the Windows 64-bit build. If you are on a Mac, stop here and ask the VHI lead which route to take before downloading anything. [confirm the team's macOS path]

1

Install GlobalProtect and connect to the campus VPN

Do this first, on any network. You only set it up once — after that GlobalProtect remembers your login.

  1. Go to the MyStudent VPN portal.
  2. Log in with your MyCalStateLA ID email address and password.
  3. Download and install the GlobalProtect client for your operating system.
  4. Run GlobalProtect. The icon sits in the bottom-right system tray on Windows, top-right menu bar on macOS.
  5. On the Home tab, under Portal, type mystudentvpn.calstatela.edu and click Connect.
  6. Log in again when prompted.
Done whenGlobalProtect reads Connected and the gateway shows mystudentvpn.

Steps 1–3 are first-time setup only. Every login after this is just opening the app and clicking Connect. Full instructions: calstatela.edu/its/network/vpn

2

Extract the installer folder

Get the installer from the VHI/NX lead, then extract the whole archive. Do not try to run anything from inside the zip.

Done whenYou have a real folder, not a zip, and you can open it.
3

Open the folder and find Launch.exe

Inside you will see a handful of files and five subfolders. You want Launch.exe — the 138 KB application, not Launch.hta and not the Launch folder.

Double-click it.

4

Click Install NX

The Siemens launcher opens with five buttons. Take the second one, Install NX. You do not need NX Launcher or Mapped Drive Installation.

5

Setup Wizard welcome → Next

Nothing to change here.

6

Custom Setup → leave the defaults → Next

Do not add or remove features. The default set is what the team supports, and changing it here is how two members end up with different NX installs that behave differently on the same part file.

Check the two things this screen tells you: it installs to C:\Program Files\Siemens\NX2206\ and it needs 8095 MB of disk. If you are short on space, fix that now rather than halfway through.

7

Licensing — the one field that matters

Into the box labelled License File or Port@host, type this exactly. Use the copy button rather than retyping it — a single wrong character here is the most common reason an install “fails”.

29000@cs-host2.calstatela.edu
Done whenThe field contains the string above with no leading space, and GlobalProtect still says Connected.
8

Language → English → Next

Leave Runtime Language on English so everyone's menus match when someone screen-shares.

9

Check the summary, then Install

This screen is your last chance to catch a typo. Read all three lines back before clicking Install, then leave it alone — it takes a while.

Done whenThe installer finishes without an error dialog.

Prove it worked

Installing is not the same as working. With GlobalProtect connected, launch NX and wait for it to fully open. If it opens to the start screen with no licence error, you are done.

ProofA screenshot of NX open on your machine, posted in the team channel. That is what the CAD custodian needs to see before assigning you a part.

Then disconnect the VPN and try launching NX again. It should fail. Knowing which failure is the normal one means you will not file a bug the next time you are off campus.

If something goes wrong

What you seeWhat it actually isDo this
NX installs fine, then fails to launch with a licence errorYou are not on the VPN, or GlobalProtect dropped.Open GlobalProtect, confirm Connected, relaunch NX. This is the number one cause.
Licence error even while connectedAlmost always a typo in the server string.Re-run the installer and re-enter the value using the copy button above. Do not guess at other port numbers.
Installer stops partway, out of diskLess than ~8 GB free.Free space, then start again from step 3.
Double-clicking Launch.exe does nothingYou are running it from inside the zip, or Windows blocked it.Extract the archive properly first, then right-click → Run as administrator.
Anything else—Screenshot the exact error and send it to the VHI/NX lead. Do not keep changing the licence server — that turns one problem into two.
